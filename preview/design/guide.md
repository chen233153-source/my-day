# Product — Brand Guide

*A playful, mobile-first design system built on purple gradients, mint-green CTAs, and 3D depth.*

Extracted from 5 mobile app UI references (language learning, bus tickets, file manager, education, AI chat). Every screenshot shares the same DNA: purple as the dominant accent, soft lavender backgrounds, generous rounded corners, 3D-rendered icons, and mint-green secondary buttons for primary actions.

Extracted from designmd://product.

## Color roles

- **Lavender Background** (`#ede9fe`) — background: Page canvas and app background. Soft lavender wash visible in every screenshot — not plain white.
- **Dark Ink** (`#1e1b2e`) — foreground: Body text and headings on light surfaces. Deep purple-black, not pure black.
- **Purple** (`#9b5de5`) — accent: Primary brand color. Used for headers, card backgrounds, active tabs, progress bars, gradient overlays, and hero sections. Can be used as a large wash — this brand is purple-forward.
- **Mint Green** (`#34d399`) — accent-secondary: CTA buttons ('Start Now', 'Generate New', 'Create', 'Search'), progress indicators, and success states. High contrast against purple.
- **White Surface** (`#ffffff`) — surface: Card interiors, input fields, modal panels — always white inside the cards, contrasting the lavender page background.
- **Muted Purple** (`#8b85a1`) — muted: Secondary text, metadata, timestamps. Desaturated purple, not neutral grey.
- **Lavender Border** (`#d4cfe8`) — border: Dividers and card outlines. Tinted purple to match the overall palette.

## Typography

- Display: Inter
- Body: Inter
- Mono: SFMono-Regular

## Messaging pillars

- Personal greeting — every screen opens with the user's name and a warm hello.
- Progress visibility — show completion %, loaded files, lesson counts. Users see momentum.
- Action-first CTAs — 'Start Now', 'Continue French!', 'Generate New', 'Explore'. Always imperative.
