# היום שלי

אפליקציה אישית לחן, בנויה מתוך 14 המדריכים שבכספת האובסידיאן.
עברית מלאה, RTL, עובדת אופליין, כל הנתונים נשמרים על המכשיר בלבד.

---

## איך מריצים על המק

```bash
python3 -m http.server 4180 --directory /Users/chen/my-day
```

ואז לפתוח `http://localhost:4180`.

## איך זה מגיע לאייפון

השרת רץ על המק, ולכן צריך להחליט איך האייפון מגיע אליו. שלוש דרכים:

1. **רשת מקומית.** מריצים את השרת, ומהאייפון נכנסים ל-`http://<כתובת-המק>:4180`.
   מגבלה: בלי HTTPS ה-service worker לא נרשם, אז אין אופליין, והמק חייב להיות דלוק ומחובר לאותו Wi-Fi.
2. **אחסון סטטי עם HTTPS** (GitHub Pages, Netlify, Cloudflare Pages).
   זו הדרך היחידה שנותנת אופליין אמיתי ואייקון קבוע במסך הבית. דורשת חשבון וחיבור חיצוני, ולכן לא בוצעה.
3. **לבדוק על המק** בינתיים, ולהחליט על אחסון אחר כך.

בכל דרך, ההתקנה במסך הבית היא: שיתוף בספארי, ואז "הוספה למסך הבית".

## היועצת ומפתח ה-API

הצ'אט רץ מול Claude API ישירות מהדפדפן. צריך מפתח Anthropic (`sk-ant-...`),
שמזינים פעם אחת במצפן תחת הגדרות, או במסך היועצת עצמו.

- המפתח נשמר ב-localStorage על המכשיר בלבד ולא נשלח לשום מקום מלבד Anthropic.
- כל הודעה עולה כסף. שאר האפליקציה חינמית לגמרי ולא צריכה רשת.
- אם אין מפתח או אין אינטרנט, כל שאר האפליקציה עובדת רגיל.
- המודל הוא `claude-sonnet-5` ברמת מאמץ נמוכה, כדי שתשובה קצרה תחזור מהר. אפשר לשנות ב-`app.js`, ב-`DEFAULTS.settings.model`.
- קובץ הייצוא **לא** כולל את המפתח.
