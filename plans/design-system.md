3. **אסור צבע מפורש.** רק `var(--*)`. אין `#hex` בקובץ מסך
4. `dir="rtl"` ו-`lang="he"` בכל מסך

## אייקונים

SVG בקו בלבד. `viewBox="0 0 24 24"`, בלי `fill`, בלי `width`. הגדלים והעובי מוגדרים ב-CSS גלובלית.

```html
<svg viewBox="0 0 24 24"><path d="M20 6L9 17l-5-5"/></svg>
```

אסור אימוג'י כאייקון ממשק. אסור ספריית אייקונים חיצונית.

## פערים ידועים שצריך לטפל בהם

**1. אין גלילה.** `.content` הוא `height: 100%` בלי `overflow`. תוכן ארוך מהמסך פשוט נחתך. מסך "היום שלי" יהיה ארוך, אז צריך להוסיף ל-CSS אזור גלילה פנימי בין הכותרת ל-`.bottom`. **זה תיקון ל-`habit-flow.css`, לא לקובץ המסך.**

**2. שתי שיטות עיצוב בפרויקט.** 01-07 עם style פנימי, 24-36 עם CSS משותף. המסכים החדשים הולכים על המשותף. המרת הישנים היא משימה נפרדת ולא חלק מבניית מסך חדש.

**3. אין מצב ריק מוגדר.** אין מחלקה למסך בלי תוכן. יידרש כשנבנה תודות ומצפן.
